## Description

```
Hey Product Hunt 👋

I'm launching Breefy today.

The problem: creating a proper SEO brief takes 1-3 hours. Keyword research, semantic mapping, H1-H3 structure, meta tags, PAA questions, checklist... It's rigorous but repetitive work that slows down content teams.

The solution: Breefy generates a complete, actionable SEO brief in 30 seconds, using Claude Sonnet 4.6 with a highly-tuned prompt that mimics a senior SEO consultant.

What each brief contains:
→ Strategic summary (objective, audience, positioning)
→ Main keyword + 8-12 semantic keywords + 5-8 PAA questions
→ Detailed H1-H2-H3 structure with section lengths
→ Writing guidelines (tone, angle, CTAs, internal links)
→ Technical optimization (meta title, description, URL, schema, alt-texts)
→ 8-10 item publication checklist

Built-in templates:
- Blog article
- Product page
- Landing page
- Comparison article
- Pillar page (complete guide)
- How-to / Tutorial

Supports 6 languages: French, English, Spanish, German, Italian, Portuguese.

Pricing:
- Free: 3 briefs forever (no credit card)
- Starter: €19/month (50 briefs)
- Pro: €49/month (unlimited + Markdown export + public sharing)

That's 7x cheaper than Semrush and 2x cheaper than Frase.

Built in 21 days with Next.js 14, TypeScript, Prisma + Neon, NextAuth, Stripe, and Anthropic Claude API.

I'd love your feedback. Happy to answer any questions in the comments!

PS: First 100 Product Hunters get a 50% discount on Starter for 3 months with code PHLAUNCH50
```
