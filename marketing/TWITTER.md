## Thread 2 — How to write a great SEO brief (educational)

### 1/7
Comment écrire un brief SEO qui produit des articles qui cartonnent.

Un thread basé sur 500+ briefs créés. 👇

### 2/7
Erreur #1 : Oublier l'intention de recherche.

4 types possibles :
- Informationnel (comment faire X)
- Navigationnel (facebook login)
- Transactionnel (acheter X)
- Investigation commerciale (meilleur X)

Ratez l'intention, ratez l'article.

### 3/7
Erreur #2 : Négliger les PAA.

Les People Also Ask sont une mine d'or. Intégrez 5-8 questions dans votre structure, Google vous remercie avec des featured snippets.

### 4/7
Erreur #3 : Meta tags bâclés.

Le meta title doit faire 50-60 caractères.
La meta description 140-155.
Tous les deux doivent contenir le mot-clé principal.

Sans ça, votre CTR est divisé par 2.

### 5/7
Erreur #4 : Structure H1-H2-H3 incohérente.

Un seul H1. Hiérarchie respectée. Mot-clé intégré naturellement dans chaque heading.

Google analyse cette structure pour comprendre votre contenu.

### 6/7
Erreur #5 : Pas de checklist finale.

Un brief sans checklist, c'est un rédacteur qui va oublier la moitié des choses.

8-10 points : mots-clés, balises, liens internes, images, schema, mise à jour.
